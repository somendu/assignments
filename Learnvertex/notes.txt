moving from one route to another 

	Here's a breakdown of how it works:

	Route Handler Accesses Event Bus:  A route handler in your Vert.x web application can access the event bus using the vertx instance available in the RoutingContext.

	Sending and Receiving Messages: The route handler can then send messages to specific addresses on the event bus using vertx.eventBus().send(address, message).  On the receiving end, another verticle (potentially another route handler) can subscribe to that address using vertx.eventBus().consumer(address, handler). The handler will be invoked whenever a message is sent to that address.

Transaction Logging - TLS


TLS Handshake Logs: Some applications or servers might offer options to log details about the TLS handshake process. This could include information like:

			TLS version used
			Cipher suites negotiated
			Certificate details (without private key information)
			Success or failure of the handshake
			
Security Event Logs: Security software or firewalls might log events related to TLS connections. This could include:

		Connection attempts
		Certificate validation results (e.g., expired certificate)
		Suspicious activity like weak cipher suites used
		
Application-Specific Logs:  Applications might log information tied to TLS connections,  like:

		User attempting to access a secure resource
		Errors during encrypted data transfer

Frontend Performance:

	//Imperative 
	public class PalindromeChecker {

	  public static boolean isPalindrome(String text) {
		text = text.toLowerCase(); // Handle case sensitivity (optional)
		int left = 0;
		int right = text.length() - 1;

		while (left < right) {
		  if (text.charAt(left) != text.charAt(right)) {
			return false;
		  }
		  left++;
		  right--;
		}
		return true;
	  }

	  public static void main(String[] args) {
		String text = "racecar";
		boolean isPalindrome = isPalindrome(text);
		System.out.println(text + " is palindrome: " + isPalindrome);
	  }
	}
	
	
	//Declarative 
	public class PalindromeChecker {

	  public static boolean isPalindrome(String text) {
		text = text.toLowerCase(); // Handle case sensitivity (optional)
		StringBuilder reversed = new StringBuilder(text).reverse();
		return text.equals(reversed.toString());
	  }

	  public static void main(String[] args) {
		String text = "madam";
		boolean isPalindrome = isPalindrome(text);
		System.out.println(text + " is palindrome: " + isPalindrome);
	  }
	}

public class CharCount {

  public static void main(String[] args) {
    String str = "Mississippi";
    HashMap<Character, Integer> charCountMap = new HashMap<>();

    for (char c : str.toCharArray()) {
      int count = charCountMap.getOrDefault(c, 0);
      charCountMap.put(c, count + 1);
    }

    System.out.println("Character counts:");
    for (Character key : charCountMap.keySet()) {
      System.out.println(key + ": " + charCountMap.get(key));
    }
  }
}
